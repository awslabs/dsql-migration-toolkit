# mysql-dsql-migrator — User Manual

A guided manual for migrating **Amazon RDS / Aurora MySQL** to **Amazon Aurora
DSQL** with this tool.

## Choose your language / 언어 선택 / 言語選択

- 🇬🇧 **[English](en/README.md)**
- 🇰🇷 **[한국어](ko/README.md)**
- 🇯🇵 **[日本語](ja/README.md)**

---

The manual is written for an engineer who knows MySQL well but is **new to Aurora
DSQL**. It covers set up, Evaluation, Schema Conversion, Full Load, streaming CDC
(and how DSQL constraints are handled), Validation, the cut-over to DSQL, and
limitations.

> **English is the source of truth.** The Korean and Japanese translations follow
> it and may lag behind; if they differ, the English version is
> authoritative.
